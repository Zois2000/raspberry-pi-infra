* Repo for an Raspberry pi infrastructure.



This pi will manage different applications as well as the Server infrastructure. Following Points will be managed by it:



\-Base Server configuration

\-Network configuration

\-MQTT broker config

\-systemd Services

\-security config

\-deployment support

\-ansible Automation





The System is build on an Raspberry pi 3 node b with ubuntu Server 24.04 LTS.
